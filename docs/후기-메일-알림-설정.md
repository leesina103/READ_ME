# 후기 제출 메일 알림

후기 폼 제출 → READ ME → Resend → 기존 인터뷰 알림 수신 주소 순서입니다.
Resend의 기존 API 키와 발신자를 재사용하므로 후기용 키를 별도로 만들 필요는 없습니다.

## 운영 설정

1. 서버에 `TALLY_REVIEW_SIGNING_SECRET`을 충분히 긴 임의의 비밀값으로 설정합니다. 채팅이나 저장소에 값을 남기지 않습니다.
2. 변경한 사이트와 환경변수를 배포합니다.
3. Tally 후기 폼 `pbQKJb`의 Integrations → Webhooks에서 다음 주소를 등록합니다.
   `https://read-me-two-black.vercel.app/api/webhooks/tally-review`
4. Signing secret에 서버와 동일한 값을 입력합니다.
5. 폼의 숨김 필드 `cohort`, `event`, `session`이 제출 데이터에 포함되는지 확인합니다.
6. 테스트 후기를 한 번 제출하고 Tally 전달 내역, Resend 발송 내역, 실제 Gmail 수신을 확인합니다.

메일 제목 예시: `[READ ME] 1기 · 1회차 후기 접수`

1기 후기 링크: https://docs.google.com/spreadsheets/d/1DvNfmCCqZAO1itKGlxxTpT08df9q5os1-mkjb4rItHs/edit

다른 기수 또는 기수 정보가 없는 제출은 Tally 응답 목록으로 연결합니다.
구글 파일 공유 범위를 넓힐 필요는 없습니다. 수신자가 파일 접근 권한을 가진 계정으로 열면 됩니다.
이 알림은 제출 접수 알림이며 구글 시트 저장 성공을 보증하지 않습니다.
Resend API 접수 성공과 실제 메일 배달은 별도로 확인해야 합니다.
동일 제출에 대한 Resend 중복 방지는 24시간 동안 적용됩니다. 이후 수동 재전송 시 다시 발송될 수 있습니다.
발송 실패 시 서버는 오류를 반환해 Tally가 재시도하게 합니다.

참고: https://tally.so/help/webhooks
참고: https://resend.com/docs/dashboard/emails/idempotency-keys
