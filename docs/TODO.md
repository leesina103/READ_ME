# TODO 관리 위치

앞으로 후속 작업과 진행 상태는 [웹페이지 구성 Google 문서](https://docs.google.com/document/d/1o-3FCnxK8BR6ddn7LkxZCyy_D5S9BAbZC16-opWVP6A/edit?tab=t.0)의 **To-do List**에서 관리합니다.

1기 이후 후기 전환 항목은 **To-do List → 완성 후 → Story — 1기 이후 READ ME 후기 전환 TODO**에 정리했습니다. 변경할 문구, 유지할 제목·소개·구조와 검증 항목은 해당 문서를 기준으로 확인하고 갱신합니다.

이 파일에는 세부 TODO를 중복해서 적지 않습니다.
