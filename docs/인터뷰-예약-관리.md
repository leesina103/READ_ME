# 인터뷰 예약 변경·취소

- 신규 예약: `/interview/apply`
- 예약 관리: `/interview/apply/manage/[전용 토큰]`
- 예약 완료 화면과 확정 알림의 관리 링크로 접근합니다. 로그인은 필요하지 않습니다.
- 운영자는 `/admin/interviews`에서 해당 예약의 ‘관리 링크 복사’를 눌러 카카오톡으로 전달할 수 있습니다. 기존 예약도 같은 방법으로 링크를 복사합니다.
- 일정 변경은 신규 예약과 같은 달력·시간 선택 화면을 사용합니다.
- 링크를 가진 사람은 해당 예약을 관리할 수 있으므로 전달하지 않습니다. 이름·전화번호로 예약을 조회하는 기능은 없습니다.
- 시작 전까지 변경·취소할 수 있습니다. 새 시간이 마감되면 기존 예약은 유지됩니다.
- 변경·취소된 시간은 다른 사람이 다시 예약할 수 있습니다. 취소한 링크로 예약을 복구할 수는 없습니다.
- 기존 예약에는 DB에서 관리 토큰이 생성되지만 이미 발송된 카톡에 링크가 자동 추가되지는 않습니다.

## 카카오 발송 연결

`INTERVIEW_CONFIRMATION_WEBHOOK_URL`이 없으면 예약 자체는 저장되고, 완료 화면에서 전용 링크를 제공합니다.
발송 서비스는 `interview.confirmed`, `interview.rescheduled`, `interview.cancelled` 이벤트를 처리해야 합니다.
예약 식별자는 `interview.applicationId`입니다. 변경·취소 이벤트에는 `updatedAt`과 `reminder.operation`도 전달합니다.

1시간 전 자동 발송 기능은 아직 구현되지 않았습니다. 발송 서비스를 연결할 때 다음 처리가 필요합니다.

- 변경 시 같은 예약의 이전 알림을 제거하고 변경된 시간으로 재설정합니다.
- 취소 시 대기 중인 알림을 제거합니다.
- 이벤트 중복·순서 역전을 처리하고 발송 직전 DB의 최신 예약 상태와 시간을 재확인합니다.
- 웹훅 실패 시에도 DB 변경은 유지됩니다. 운영자 예약 목록에서 실제 상태를 확인하고 필요한 안내를 별도로 보냅니다.

## 검증

`node scripts/test-interview-bookings.mjs [PGlite의 dist/index.js 절대 경로]`로 격리된 PostgreSQL에서 권한·마감 시간·변경 실패 시 원래 예약 유지·취소 후 재예약을 검증합니다.
