# READ ME 가이드 기능·권한·운영 매뉴얼

2026년 10월 23일 · 최신 커밋 8c31b3a 기준

가이드를 초대하고 승인하는 운영자와, 모임을 준비하고 진행하는 가이드가 함께 참고하는 안내서입니다. 화면 경로와 버튼 이름을 기준으로 정리했습니다. 기준 커밋까지의 구현을 설명하며, 실서비스 배포·실제 계정 동작을 이번 문서 작업에서 새로 검증한 것은 아닙니다.

## 1. 현재 운영 원칙

- 가이드는 담당 모임의 참여 회원이기도 합니다. 승인하거나 담당 모임을 저장하면 현재 기수·회원 자격·참여 모임이 함께 연결됩니다.
- 한 가이드는 담당·참여 모임 하나를 맡고, 한 모임에는 가이드 한 명을 배정합니다.
- 운영자는 전체 모임을 관리하고, 가이드는 배정된 모임을 관리합니다. 가이드 역할과 담당 모임은 운영자만 지정합니다.
- 가이드 역할을 해제해도 회원 자격과 참여 기록은 유지됩니다. 다른 기수로 재배정해도 기존 참여 이력은 남습니다.
- 전체 운영자로 승격하는 기능은 이 가이드 관리 기능에 포함되지 않습니다.

## 2. 화면별 사용 범위

### 운영자 화면

- /admin/roles · 가이드 권한 관리: 승인 대기, 가이드 목록·배정, 회원에서 지정, 가입 초대의 네 탭으로 관리합니다. 이름·닉네임·이메일로 대상을 찾습니다.
- /admin/members · 기수 회원 명단: 운영자, 전체 가이드, 기수별 명단을 확인합니다. 기수별로 가이드·가입 완료·가입 대기를 구분합니다.
- /admin/cohorts · 기수 일정 관리: 기수 일정과 모임별 참여 명단을 확인합니다.
- /guide · 가이드 모임 관리: 운영자는 전체 모임의 명단·공개된 답변·모임 안내를 확인하고 수정할 수 있습니다.

### 가이드 화면

- /guide · 담당 모임 목록: 기수·모임 이름, 1주차 일정, 장소, 종료 여부가 보입니다. 담당 모임이 없으면 배정을 요청하라는 안내가 나옵니다.
- /guide/groups/[모임 ID] · 담당 모임 상세: 모임 정보, 회차 일정, 가입 완료 명단, 가입 대기 인원, 안내·일정 수정, 최근 모임 변경 기록이 있습니다.
- /guide/groups/[모임 ID]/answers · 공개된 주차 답변: 담당 참여자의 공개된 답변을 읽기 전용으로 확인합니다. 아직 열리지 않은 주차는 표시하지 않습니다.
- /guide/resources · 가이드 자료: 준비·진행 순서와 기록 원칙을 확인합니다.
- /my 및 /membership · 회원 공간: 승인·배정으로 연결된 기수의 회원으로 참여합니다. /my에서 가이드 모임 관리로 이동할 수 있습니다.

일반 회원과 승인 대기 가이드는 가이드 모임 상세·답변·자료에 접근할 수 없습니다. /guide에서는 미지정·승인 대기·승인 거절·역할 해제 상태에 맞는 안내를 봅니다. 가이드에게 다른 모임 주소를 알려주어도 그 모임의 관리 데이터는 열리지 않습니다. /admin의 권한 관리는 운영자만 이용합니다.

## 3. 신규 가이드 초대와 승인

1. 운영자가 /admin/roles → 가입 초대 → 초대 링크 만들기를 누릅니다. 상대방의 이메일을 미리 입력하지 않습니다.
2. 사용 가능한 초대에서 링크 다시 보기를 누르고 링크를 복사해 직접 전달합니다. 링크 접기로 다시 숨길 수 있습니다.
3. 초대받은 사람이 /guide/join/[초대 토큰]에서 이름·이메일·비밀번호를 입력해 가입합니다.
4. 가입자는 이메일 인증을 마친 뒤 닉네임을 설정합니다. /guide에서는 승인 대기 안내를 봅니다.
5. 운영자가 승인 대기 탭에서 이름·이메일·닉네임을 확인합니다. 이메일 인증이나 닉네임 설정이 끝나지 않으면 승인할 수 없습니다.
6. 담당·참여 모임 하나를 고르고 승인하고 배정을 누릅니다. 승인 성공 시 회원 자격과 참여 모임도 함께 연결됩니다.
7. 가이드가 /guide를 다시 열어 담당 모임을 확인하고, 회원 공간에서도 참여 기수와 모임을 확인합니다.

초대 링크는 7일 동안 한 번 사용할 수 있습니다. 이미 가입한 사람은 새 계정을 만들지 않고 ‘회원에서 지정’을 사용합니다. 초대 링크 전달과 승인 결과 안내는 운영자가 직접 합니다. 가입 이메일 인증 메일만 기존 인증 서비스에서 발송하며, 초대·승인 알림 메일은 자동으로 보내지 않습니다.

## 4. 초대 링크 상태와 정리 — 최신 추가 기능

### 사용 가능한 초대

미사용 상태이고 만료·취소되지 않은 초대가 표시됩니다. 발급·만료 시각을 보고 링크를 다시 확인하거나 초대 취소를 할 수 있습니다. 이전 방식으로 발급돼 링크 원문이 없는 초대는 다시 볼 수 없으므로 원문을 가지고 있지 않다면 취소 후 새로 발급합니다.

### 사용 완료

가입 초대 탭에 ‘사용 완료 · N개’ 구역이 생겼습니다. 해당 링크로 가입을 마친 사람의 이름·닉네임과 초대 발급 시각을 보여줍니다. 사용 완료는 링크로 회원가입을 마쳤다는 뜻입니다. 이메일 인증·닉네임 설정·운영자 승인까지 끝났다는 뜻은 아닙니다.

- 사용 완료된 링크는 다시 사용할 수 없고 다시 보기·취소 대상에서도 제외됩니다.
- 사용 완료 기록은 초대 유효기간이 지나도 보관합니다. 화면에 표시하는 날짜는 가입 완료 시각이 아니라 초대 발급 시각입니다.
- 미사용 초대를 취소하면 해당 초대가 삭제됩니다. 미사용 상태로 만료된 초대는 가이드 관리 목록을 불러올 때 정리됩니다. 별도 예약 작업이 주기적으로 실행되는 방식은 아닙니다.
- 초대 발급·취소 기록은 최근 권한·모임 변경 기록에 쌓지 않습니다. 사용 완료는 가입 초대 탭에서 확인합니다.
- 초대 정리는 기존 회원 자격과 담당 모임 배정을 해제하는 작업이 아닙니다.

## 5. 기존 회원 지정·재배정·회원 자동 연결

1. /admin/members에서 대상 회원의 가이드 지정·관리를 누르거나, /admin/roles → 회원에서 지정에서 대상을 찾습니다.
2. 담당·참여 모임 하나를 선택하고 가이드로 지정을 누릅니다. 신규 초대나 승인 대기 절차는 별도로 거치지 않습니다.
3. 기존 가이드의 모임을 바꾸려면 가이드 목록·배정에서 모임을 선택하고 담당 모임 저장을 누릅니다.
4. 저장 후 기수 회원 명단에서 참여 기수·담당 모임·연결 상태를 확인합니다.

- 다른 가이드가 담당 중인 모임은 중복 배정할 수 없습니다. 기존 담당을 먼저 해제하거나 다른 모임으로 옮겨야 합니다.
- 종료된 기수에는 새로 배정할 수 없습니다. 모임 정원도 적용됩니다. 정원이 가득 차거나 회원 정보 연결이 충돌하면 오류 안내가 나오며 관련 변경 전체가 취소됩니다.
- 승인·재배정 시 현재 기수, 활성 회원 자격, 회원 명단, 참여 모임을 함께 연결합니다. 가이드도 현재 기수 답변 작성과 커뮤니티 글쓰기에 참여할 수 있습니다.
- 이 기능 이전에 승인한 가이드에게 ‘회원 연결 필요’가 표시되면 배정·연결 관리로 이동해 담당 모임을 다시 저장합니다.
- 다른 기수로 재배정하면 현재 기수와 참여 모임이 바뀌고 지난 참여 이력은 유지됩니다.

### 승인 거절과 역할 해제

승인 대기 중에는 승인 거절, 활동 중인 가이드에게는 가이드 역할 해제를 사용할 수 있습니다. 역할 해제는 담당 모임의 관리 권한과 배정을 제거하지만 회원 자격과 개인 기록은 유지합니다. 해제 이후 새 조회·저장은 차단되지만 이미 열어 둔 화면에 전달된 정보까지 원격으로 지우지는 않습니다.

## 6. 가이드가 볼 수 있는 정보

- 담당 모임에서 가입을 마친 참여자의 이름·닉네임을 봅니다. ‘총 N명’은 가입 완료 인원이며 가입 대기자는 별도 숫자로 표시됩니다.
- 장소, 4회차 일정, 소요 시간, 가이드 이름·소개를 확인합니다.
- 공개된 주차의 담당 참여자 답변은 자기 답변을 먼저 쓰지 않아도 읽을 수 있습니다. 다른 사람의 답변을 수정할 수는 없습니다.
- 회원 공간의 가이드 조회 권한은 담당 기수까지이며, 기존 회원으로서 가진 참여 이력 권한도 유지됩니다. 운영자는 전체 기수를 조회할 수 있습니다.
- 회원 공간에서는 선택한 기수의 자기소개와 공개된 답변을 조회합니다. 가이드 관리 화면의 ‘담당 모임’ 범위와 회원 공간의 ‘기수’ 범위를 구분합니다.
- 자기소개는 현재 기수 동료와 해당 기수 담당 가이드·운영자에게 공개됩니다. 일반 회원에게 다른 기수의 소개를 공개하는 것은 아닙니다.
- 회원의 전화번호·이메일·출생연도·결제 내역·신청서는 가이드 화면에 제공하지 않습니다.
- 개인 답변 작성은 본인이 참여하는 현재 기수에서 합니다. 지난 기수와 종료된 기수는 읽기 전용입니다.

## 7. 모임 안내와 일정 수정

/guide/groups/[모임 ID]의 ‘모임 안내·일정 수정’에서 가이드 이름·소개, 장소, 소요 시간(30~480분), 미래 회차 일정을 바꿀 수 있습니다. 4회차 일정은 한국 시간 기준으로 입력합니다.

1. 안내 문구나 일정을 수정합니다. 일정은 기수 기간 안에서 회차 순서대로 입력합니다.
2. 변경 내용 확인을 눌러 변경 전후를 비교합니다.
3. 확인하고 저장을 누릅니다. 다른 사람이 먼저 수정했다면 새로고침 후 최신 내용으로 다시 확인합니다.
4. 회원 화면을 새로고침해 반영 내용을 확인하고, 참여자에게 변경 사항을 직접 안내합니다.

- 이미 지난 회차 일정은 수정할 수 없습니다. 종료된 기수는 모임 안내를 포함한 모든 수정이 차단됩니다.
- 일정 변경은 주차별 질문 공개 시각과 작성 마감에도 영향을 줍니다.
- 저장해도 문자나 이메일은 자동 발송되지 않습니다. 일정·장소 변경 안내는 별도 수동 업무입니다.
- 모임 추가·삭제·이름 변경, 정원, 신청 접수 여부, 회원 승인·입금·취소·배정, 기수 시작·종료일, 가이드 담당 변경은 운영자에게 요청합니다.

## 8. 변경 기록과 진행 자료

/admin/roles 아래 ‘최근 권한·모임 변경 기록’에서는 변경 시각·작업자·대상 가이드, 이전 담당과 새 담당 모임 등을 확인합니다. 최근 50개를 표시하며 기록 비우기를 누르면 기존 표시 기록을 숨기고 이후 변경부터 보여줍니다. 회원이나 배정을 삭제하는 버튼은 아닙니다. 과거 일부 기록의 이름·일정은 현재 정보로 보완해 표시한다는 안내가 붙습니다.

담당 모임 상세의 ‘최근 모임 변경 기록’에서는 장소·소요 시간·일정의 변경 전후를 확인합니다. /guide/resources에는 기본 준비·진행 안내가 있으며 별도 발제문·운영 자료의 업로드·편집 기능은 아직 없습니다. 운영자가 전달한 최신 자료를 사용합니다.

토의 기록은 ‘토의 전 내가 생각한 답 → 오늘 새로 들은 관점 → 다음 주에 살펴볼 행동이나 질문’의 세 단계로 돕습니다.

## 9. 함께 반영된 운영자·회원 화면 변경

### 기수 회원 명단과 가이드 연결 상태

/admin/members에는 운영자와 전체 가이드를 각각 묶고, 아래에 기수별 가이드·가입 완료·가입 대기를 표시합니다. 가이드 표에서 이름·닉네임·참여 기수·담당 모임·회원 연결 완료/필요·배정·연결 관리 버튼을 볼 수 있습니다. 회원 연결이 완료된 가이드는 같은 기수의 회원 명단에도 포함되므로 서로 다른 사람으로 중복 계산하지 않습니다. 다른 기수로 이동한 회원은 이전 기수 목록에 현재 기수를 함께 보여줍니다.

### 가입 대기 회원 삭제

/admin/members의 가입 대기 명단에서 ‘명단에서 삭제’를 누르면 이름·이메일·기수를 확인하는 창이 열립니다. 삭제하면 해당 가입 승인을 취소하고 배정된 모임의 자리를 해제합니다. 그 승인으로는 가입할 수 없지만 기존 신청 내역은 보관합니다. 이미 가입한 회원은 이 기능으로 삭제할 수 없으며, 대상 정보가 바뀐 경우에도 삭제를 막습니다. 이는 가이드 초대 취소와 별개의 기능입니다.

### 운영자 메뉴와 회원 메뉴

/admin 메뉴는 인터뷰 예약 → 가입 신청 관리 → 기수 일정 관리 → 기수 회원 명단 → 가이드 권한 관리 → 가이드 모임 관리 → 북토의·소모임 관리 순서입니다. 가이드 권한 관리는 사람의 권한과 배정을, 가이드 모임 관리는 실제 모임의 명단과 안내를 다룹니다.

/membership의 가로 메뉴에 좌우 이동 버튼을 추가했습니다. 좁은 화면에서 가려진 메뉴를 이동해 볼 수 있고, 현재 페이지 메뉴가 보이도록 위치를 조정합니다. 더 이동할 메뉴가 없는 방향은 버튼이 비활성화됩니다.

## 10. 운영 점검 목록

- 신규 초대 가입 후 ‘사용 완료’가 표시되고, 인증·닉네임·운영자 승인 전에는 모임 관리가 열리지 않는지 확인합니다.
- 담당 모임 하나로 승인한 뒤 /guide, /my, 회원 공간, 기수 회원 명단의 기수·모임·연결 상태가 일치하는지 확인합니다.
- 다른 모임 관리 주소와 아직 공개되지 않은 주차 답변이 차단되는지 확인합니다.
- 모임 장소·미래 일정 수정 시 전후 비교, 회원 화면 반영, 질문 공개·마감 영향을 확인하고 참여자에게 직접 안내합니다.
- 역할 해제 후 모임 관리 접근은 막히고 회원 자격·기록은 유지되는지 확인합니다.
- 사용 완료 링크 재사용, 취소·만료 링크 가입이 차단되고 사용 완료 기록은 남는지 확인합니다.
- 가입 대기 회원 삭제와 가이드 초대 취소를 구분하고, 승인 취소 시 기존 신청 내역이 보관되는지 확인합니다.
- 모바일과 데스크톱에서 명단·회원 메뉴·승인 화면을 확인합니다.

이 목록은 운영자가 실제 계정으로 확인할 절차입니다. 이번 작업은 커밋과 구현을 바탕으로 문서를 작성한 것이며, 실서비스 배포 상태·인증 메일 수신·실제 승인 전체 과정의 통과를 새로 보증하지 않습니다. 기존 권한 문서의 테스트 통과 기록은 이전 작업 기록으로 취급합니다.
