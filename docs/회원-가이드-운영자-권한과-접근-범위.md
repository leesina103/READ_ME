# 회원·가이드·운영자 권한과 접근 범위

작성일: 2026-10-22 · 수정일: 2026-10-23

문서 분류: 웹사이트와 회원관리. 프로젝트 작업 규칙에 따라 로컬에 보관합니다.

## 역할의 기준

- 가이드는 참여 회원이기도 합니다. 승인·재배정 시 선택한 모임으로 현재 참여 기수가 연결되며, 가이드 역할만 해제하면 회원 자격과 참여 기록은 유지됩니다.
- 가이드는 운영자가 승인하고 담당 모임을 배정해야 활동할 수 있습니다. 본인이 역할을 선택하거나 승격할 수 없습니다.
- 한 모임에는 한 명의 가이드를 배정합니다. 한 가이드에게 담당·참여 모임 하나를 배정합니다.
- 전체 운영자 승격은 이번 기능에 포함하지 않습니다.
- 접근 권한은 **운영자 > 가이드 > 회원** 순서입니다. 운영자는 전체 기수의 가이드·회원 화면을, 가이드는 담당 모임이 속한 기수의 회원 화면을 이용합니다. 가이드와 회원을 겸하면 기존 회원 참여 이력도 유지됩니다.

## URL별 권한

| 화면 | 회원 | 승인 대기 가이드 | 승인된 가이드 | 운영자 |
| --- | --- | --- | --- | --- |
| `/my` 나의 서재 | 기존 회원 기능 | 가이드 승인 상태로 이동 | 배정한 기수의 회원 기능 이용 | 기존 기능 |
| `/membership/*` 회원 공간 | 기존 기수·멤버십 정책 | 가이드 가입만으로 이용 불가 | 담당 기수 접근 + 기존 회원 자격 | 전체 기수 접근 |
| `/guide` 가이드 모임 관리 | 가이드 미지정 안내 | 승인 대기 안내 | 담당 모임 목록 | 전체 모임 목록 |
| `/guide/groups/[id]` 모임 관리 | 접근 불가 | 접근 불가 | 담당 모임만 조회·수정 | 전체 모임 조회·수정 |
| `/guide/groups/[id]/answers` 주차 답변 | 접근 불가 | 접근 불가 | 담당 참여자의 공개된 주차 답변만 읽기 | 전체 모임의 공개된 답변 읽기 |
| `/guide/resources` 가이드 자료 | 접근 불가 | 접근 불가 | 읽기 가능 | 읽기 가능 |
| `/admin/roles` 가이드 권한 관리 | 접근 불가 | 접근 불가 | 접근 불가 | 초대·승인·거절·지정·해제·배정 |
| `/admin/members` 회원 명단 | 접근 불가 | 접근 불가 | 접근 불가 | 기존 회원을 가이드로 지정하는 버튼 |
| 기타 `/admin/*` | 접근 불가 | 접근 불가 | 접근 불가 | 기존 기능 유지 |

가이드와 회원을 겸하는 사람은 회원으로 가진 권한도 그대로 가집니다. 가이드에게 미배정 모임 URL을 전달해도 해당 화면과 데이터는 열리지 않습니다. 이미 화면에 전달된 내용까지 원격으로 지울 수는 없지만, 해제 후의 조회·저장은 차단됩니다.

## 신규 가이드 초대

1. 운영자가 `/admin/roles` → **가입 초대**에서 링크를 만듭니다. 운영자는 상대의 이메일을 입력하지 않습니다.
2. 새 링크를 복사해 직접 전달합니다. 링크는 7일간 유효하고 한 번 가입하면 소모됩니다. 유효한 미사용 초대는 가입 초대 목록의 **링크 다시 보기**에서 다시 복사할 수 있습니다. 이전 방식으로 발급해 원문이 저장되지 않은 초대는 새로 발급합니다.
3. 상대가 자신의 이름·이메일·비밀번호를 입력합니다. 이메일 인증 후 닉네임을 정합니다.
4. `/guide`에 **승인 대기**가 표시됩니다. 이 상태에서는 명단·답변·모임 수정 기능을 사용할 수 없습니다.
5. 운영자가 **승인 대기**에서 이름·이메일·닉네임을 확인하고 담당 모임을 선택한 뒤 **승인하고 배정**을 누릅니다. 이메일 인증과 닉네임 설정 전에는 승인할 수 없습니다.
6. 가이드가 `/guide`를 다시 열면 담당 모임이 보입니다.

이미 가입한 사람은 새 계정을 만들 필요가 없습니다. 아래 회원 지정 흐름을 사용합니다. 초대 메일·승인 알림 메일은 자동 발송하지 않습니다. 가입 시 이메일 인증 메일만 기존 인증 서비스가 보냅니다.

## 기존 회원을 가이드로 지정

1. `/admin/members`에서 대상 회원의 **가이드 지정·관리**를 누릅니다.
2. `/admin/roles`의 해당 회원을 확인합니다.
3. 담당·참여 모임을 하나 고르고 **가이드로 지정**합니다. 별도 초대와 승인 대기 절차는 없습니다.
4. 회원의 `/my`에 **가이드 모임 관리로 가기**가 표시됩니다.

다른 가이드가 맡은 모임은 중복 배정할 수 없습니다. 기존 가이드의 담당 모임에서 제외하거나 역할을 해제한 뒤 새 가이드에게 배정합니다. 종료된 기수는 새로 배정할 수 없습니다. 역할을 해제하면 모든 가이드 배정이 제거되며 회원 자격은 유지됩니다.

## 가이드가 보고 수정하는 범위

### 읽기

- 담당 모임의 가입 완료 인원과 이름·닉네임 명단. **총 인원에 가입 대기자는 포함하지 않습니다.** 가입 대기는 숫자만 표시합니다.
- 장소, 회차별 일정, 소요 시간, 가이드 소개.
- 담당 모임 참여자의 공개된 주차 답변. 가이드는 자기 답변을 먼저 쓰지 않아도 읽을 수 있으며 수정할 수 없습니다.
- 회원 공간 상단에서 조회 기수를 선택합니다. 가이드에게는 담당 기수만, 운영자에게는 모든 기수가 표시됩니다. 회원 공간에서는 선택한 기수 전체의 자기소개와 공개된 답변을 조회합니다.
- 개인 답변·소개 작성은 본인이 참여자로 가입한 현재 기수에서 합니다. 운영·가이드 권한으로 방문한 다른 기수는 조회용이며 다른 사람의 글을 수정할 수 없습니다.
- 담당 모임이 여러 개일 때 회원 공간의 주차 공개 일정은 본인 참여 모임을 우선하고, 없으면 담당 모임 중 이름순 첫 모임을 기준으로 합니다. 모임별 일정·답변은 가이드 모임 관리에서 따로 확인합니다.
- 종료된 기수는 담당 배정이 유지되어 있는 동안 읽기 전용입니다.
- 회원의 전화번호·이메일·출생연도·결제 내역·신청서는 가이드 화면에 제공하지 않습니다.
- 자기소개는 현재 기수 동료와 해당 기수 담당 가이드·운영자에게 공개합니다. 입력 화면에도 이 범위를 안내합니다. 일반 회원이 다른 기수의 소개를 볼 수 있도록 바꾸지는 않습니다.

### 수정

- 담당 모임의 가이드 이름·소개, 장소, 소요 시간(30~480분), 미래 회차 일정.
- 변경 내용 확인 → 변경 전후 비교 → 저장 순서입니다. 일정은 기수 기간 안에서 회차 순서대로 입력합니다.
- 지난 회차는 변경할 수 없습니다. 종료된 기수는 모든 수정이 차단됩니다.
- 동시에 다른 사람이 수정했으면 저장을 막고 새로고침을 요청합니다.
- 저장자는 누구인지, 언제 무엇을 바꿨는지 기록합니다.

### 운영자에게 요청할 일

- 그룹 추가·삭제·이름 변경, 정원, 신청 접수 여부.
- 회원 승인·입금·취소·배정, 가이드 역할·담당 모임 변경.
- 기수 시작일·종료일 변경.

**일정 변경은 주차별 질문의 공개 시각과 작성 마감에도 영향을 줍니다. 저장 후 참여자 안내는 직접 해야 하며 문자나 메일이 자동 발송되지 않습니다.**

## 자료 관리

`/guide/resources`에는 기본 진행 안내를 넣었습니다. 발제문 파일과 별도 운영 자료 업로드·편집 기능은 아직 없습니다. 별도 자료는 운영자가 전달한 최신본을 사용합니다.

토의 기록의 기본 순서는 **토의 전 내가 생각한 답 → 오늘 새로 들은 관점 → 다음 주에 살펴볼 행동이나 질문**입니다.

## 실제 계정으로 확인할 순서

1. 운영자 로그인 → `/admin/roles` → 초대 링크 발급.
2. 별도 브라우저에서 링크 열기 → 가이드 가입 → 이메일 인증 → 닉네임 설정.
3. 승인 전에는 승인 대기 안내만 보이는지 확인.
4. 운영자가 담당·참여 모임 하나를 선택해 승인 → 가이드 화면에 해당 모임만 표시되는지 확인.
5. 명단·가입 대기 숫자·공개된 주차 답변을 확인.
6. 소개 또는 미래 일정 변경 → 변경 전후 확인 → 저장 → 회원의 내 모임 화면에 반영되는지 확인.
7. 다른 모임 주소 접근이 차단되는지 확인.
8. 역할 해제 → 가이드 조회·저장 차단 확인. 기존 회원이면 `/my`와 회원 기록 유지 확인.
9. 사용한 초대·취소한 초대·만료된 초대로 신규 가입이 막히는지 확인.

## 검증 기록

- 격리된 PostgreSQL 가이드 검증 79개 통과: 일반 회원 가입 유지, 초대 재사용·취소·만료 차단, 승인 전 접근 차단, 이메일 인증·닉네임 조건, 모임 범위 제한, 미래 주차 숨김, 저장 충돌 방지, 역할 해제, 회원 기수 유지, 종료 기수 수정 차단, 운영자의 전체 모임 조회·수정, 가이드의 담당 기수 접근과 타 기수 차단 등.
- 기존 모임 선택·통합 저장 검증 61개 통과.
- `npm run lint`, `npm run build` 통과. 데이터베이스 변경 적용 및 RLS 활성화 확인. 실제 회원의 가이드 지정은 아직 하지 않았습니다.
- 미리보기에서 모바일 390px 1열·데스크톱 2열과 가로 넘침 없음, 저장 전 장소 변경 비교 표시를 확인했습니다. 미리보기용 임시 경로는 검증 후 제거했습니다.
- 이후 회원 카드의 이름·상태를 한 줄로 묶고, 여백·모임 선택 간격·빈 메시지 공간을 줄였습니다. 이번 압축 변경의 실제 화면 검증은 브라우저 연결 응답 지연으로 완료하지 못했습니다.
- 실제 인증 메일 수신부터 운영자 승인까지의 브라우저 검증은 위 순서로 별도 확인해야 합니다. 격리 검증은 실제 메일 수신 검증을 대신하지 않습니다.

## 가이드 승인 시 회원 자동 연결

- 운영자가 담당·참여 모임 하나를 선택해 승인하거나 저장하면 현재 기수, 회원 명단, 활성 회원 자격, 참여 모임이 함께 연결됩니다.
- 가이드도 참여 회원이므로 커뮤니티 글쓰기와 현재 기수 답변 작성이 가능합니다.
- 다른 기수로 재배정하면 기존 참여 이력은 남기고 현재 기수와 모임을 바꿉니다. 역할 해제만으로는 회원 자격을 없애지 않습니다.
- 기존 정원 제한을 적용하며 실패하면 기수·회원·가이드 변경 전체를 취소합니다.
- 이 변경 전에 승인한 가이드는 담당 모임을 다시 저장하면 자동 연결됩니다.
