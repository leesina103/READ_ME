# 인스타툰 파일 관리

- 각 편 폴더에는 최신 최종본 한 벌만 유지합니다.
- 수정할 때 기존 이미지와 원고, 미리보기를 같은 경로에서 갱신합니다.
- v2, 리뷰반영본, 날짜별 백업 폴더나 중복 ZIP, 누적 생성 기록을 만들지 않습니다. 사용자가 별도로 요청한 경우에만 만듭니다.
- 전체-미리보기.html을 유일한 전체 목록으로 유지하고 이미지 변경 시 함께 갱신합니다.
- 기존 7편과 7-1~7-5 확장편은 서로 다른 게시물입니다.
- 글씨체는 `01-인간관계/02.png`의 가늘고 단정한 한글 손글씨를 기준으로 제목, 본문, 말풍선까지 통일합니다.
- 이미지 상단의 작은 주제·편수 라벨은 넣지 않습니다. 본문 제목, READ ME와 장수 표시는 유지합니다.
- 7-1~7-5 확장편에는 하단의 다음 이야기 안내와 다음 편 제목을 넣지 않습니다.
